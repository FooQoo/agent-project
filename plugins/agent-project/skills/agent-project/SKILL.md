name: agent-project
description: Use Agent Project to plan and track work in the project bound to the current folder. Read the progress table first, inspect only needed epic details and tasks, accept the user's requests, turn a request into a Backlog plan that only a person sends to Todo, or into ordinary Todo tasks when it asks for the work, report AI progress, ask the user questions (with or without choices) on the board and in the chat, wait for their answers, and automatically record work progress in task history.
compatibility: Requires the agpj CLI on PATH and a local Agent Project data area. Commands that wait for user answers start the local agpj server when it is not running.
allowed-tools: Bash(agpj *)
