Agent Board is now Agent Project, with the `agpj` command, and this release adds planning by version, release documents, Tailscale for phone access, and simpler run states.

## Changes

- **Agent Board is now Agent Project.** The command is `agpj`, installed with `brew install fooqoo/tap/agpj`. The data folder is `~/.agent-project`, the environment variables start with `AGPJ_`, and the agent plugin is `agent-project`. The board, the phone screens, the home screen app, and notifications say Agent Project. `brew install fooqoo/tap/agboard` still installs the last Agent Board, v1.7.0, which is kept as it was.
- **Plan work by version.** Create versions from the version menu in the PC header or with `agpj version add`. Choose a version there to show only its cards, and the unplanned ones, in Todo, Doing, and Done; Backlog always shows every card, and **All** shows everything again. The button at the bottom of the menu makes the shown version the release version, and `agpj version release` sets or clears it. Each new version gets its own `docs/release/<version>.md`, copied from `docs/release/TEMPLATE.md`, and a Backlog card that asks for its release notes, planned for that version.
- **A tidier PC header.** Docs, Epics, Archive, and Settings are gathered in one menu at the right end of the header, so the project name and the version fit on a tablet in either orientation. The version button shows only a flag and the version.
- **Give tasks a planned version.** Set it in the task edit dialog, for all of an epic's tasks at once in the epic edit dialog, with `agpj add` or `agpj edit` (`--planned-version`, `--release-version`, `--unplanned`), or by hand in the `plannedVersion` field of `TASK.md`. Every change is recorded in the task's history. Cards show the version next to their date, and `agpj ls` and `agpj progress` can show only one version's tasks.
- **Change the version of finished work.** The planned version is the one field you and the AI can still change on Done and archived tasks.
- **Release documents.** `agpj release doc --version <version>` (or `--release-version`) writes a section into `docs/release/<version>.md` listing the version's planned, verified, remaining, and moved tasks, and done tasks without acceptance conditions. Running it again replaces only that section and keeps your own text. Agents can also write version reports and retrospectives on a theme across versions.
- **Record what was published.** `agpj result add <id> --published <version> --link <url>` records that a task was published in a version, also on a Done task. Release documents and reports count a task as published only with such a record.
- **Simpler run states.** A task is **Idle**, **Running**, or **Paused**, and only cards in Doing show it. A card that waits for your answer shows **Awaiting answer** in yellow instead, in any lane and for any assignee. When an agent asks you a question about a running task, the task is paused for it, and taking in your answer sets it running again. Agents cannot send a card from Doing back to Todo themselves, and pause a task only when the stalled-task reminder below says so; you can do both.
- **A reminder to review the board.** When no card has changed lane for 30 minutes and Doing holds a card that is not running, or Todo holds an AI card, agents are reminded to review those cards: resume what can continue, ask you before a waiting card goes back to Todo, and start ready Todo cards. A card whose decision was recorded in its history stays out of the reminder until the next lane move.
- **An agent can pause a stalled task.** When the reminder says a task has been running for a long time with no history entry, an agent that is not actually working on it can now pause it with `agpj state <id> paused --actor ai --reason "<why>"`, and an agent that is working on it keeps going. Agents use this only for that reminder.
- **Tailscale for phone access.** `agpj setup remote` and the PC connection settings let you choose Tailscale instead of ngrok. Tailscale needs no token or domain. Setup checks that Tailscale is installed, signed in, and has HTTPS certificates turned on, says what to do next, and shows the `ts.net` address when everything is ready. The passcode and device checks are the same as with ngrok.
- **Archive done cards by selection.** On the PC, the archive button in the Done header starts a selection with every done card picked; unpick the ones to keep and archive the rest. On the phone, use **Select and archive** at the foot of the Done lane, or swipe left past the end of the lane.
- **`mv` sends a plan to Todo.** `agpj mv <id> todo --actor human` sends a Backlog card to Todo with the same rules as before, and `--force` confirms open questions.
- **Notices at the top.** The notice after a move appears at the top right on the PC and below the header on the phone, with a close button, and goes away by itself.
- **The Summary list keeps the newest ten.** Older summaries are hidden but kept in the files.
- **The first-run guide shows Attach task.** In the guide's Ask AI step you can attach the sample cards to the request.
- **A quieter Backlog lane.** The Backlog lane on the PC no longer has a dashed frame; its cards keep their dashed outline.
- **The Japanese screens say バージョン.** Versions are written バージョン instead of 版 in the Japanese screens, history, and pages.
- **Tell the agent to start a plan.** An agent can now send Backlog work to Todo (`agpj mv <id> todo --actor ai`, `agpj epic send <EPIC-ID> --actor ai`), but only when you tell it to, for example "start the plan" in the chat. It never sends on its own judgment and cannot confirm a send with open questions. The history records "An agent sent the task to Todo." with the reason. You can still send plans yourself from the board.

## Fixes

- **The memo field stays visible on the phone.** Typing a memo on the phone answer sheet no longer leaves the field behind the footer and the keyboard.
- **Phone cards match the PC.** A phone card shows the owner icon, and labels its run state only in Doing, the same way as a PC card.
- **A moved card stays put on the phone.** After you move a card between lanes on the phone, it no longer jumps back to its old lane for a moment while the board refreshes.
- **The phone selection buttons are the same size.** The send and cancel buttons of the phone selection drawer now have the same width and height.

## Breaking changes

- **New command, data folder, and variables.** `agboard` is now `agpj`, `~/.agent-board` is now `~/.agent-project`, and `AGBOARD_*` environment variables are now `AGPJ_*`. Agent Project does not read the old folder or variables, so move them yourself (see below).
- **New agent plugin.** The plugin is `agent-project@agent-project`, its hook runs `agpj hook`, and agents receive `AGPJ_PROGRESS`, `AGPJ_ERROR`, and `AGPJ_NOTICE`. Codex uses `~/.codex/rules/agpj.rules`. The old `agent-board` plugin does not work with `agpj`.
- **Phone and ngrok sign-in start over.** The remote access cookies and the keychain entry have new names, so each phone signs in again with the passcode, and a saved ngrok token has to be saved again.
- **Other renamed names.** HTTP headers start with `X-Agpj-`, the release document markers are `<!-- agpj:generated:start -->` and `<!-- agpj:generated:end -->`, and the code signing identifier is `io.github.FooQoo.agent-project.agpj`.
- **`agboard send` is removed.** Use `agpj mv <id> todo --actor human`, with `--force` to confirm open questions.
- **Run states are `idle`, `running`, and `paused`.** `pending` is no longer a run state, and a file that stores it is reported as invalid. Waiting for an answer is now the `awaitingAnswer` flag in the task JSON, set while the task refers to an open question; list such tasks with `agpj ls --awaiting-answer`. Only AI tasks in Doing can be `running` or `paused`, a task that enters or leaves Doing becomes `idle`, and in Doing only idle to running, running to paused, and paused to running are allowed; other changes are refused with `invalid_state_change`.
- **New storage format name.** The shared folder's `workspace.json` now says `"format": "agpj-files"`. A folder that still says `agboard-files` is reported as invalid and left untouched.

## Required update steps

Install the new command. The old `agboard` formula stays and is not replaced:

```sh
brew install fooqoo/tap/agpj
```

Move the data folder before you run `agpj` for the first time. If `~/.agent-project` already exists, `mv` puts the old folder inside it as `~/.agent-project/.agent-board`. In that case, first stop `agpj` with `agpj stop` and rename the existing folder out of the way, for example to `~/.agent-project.new`. If the move already happened, move the folder back with `mv ~/.agent-project/.agent-board ~/.agent-board` and start again.

To keep your boards, stop the old server, move the data folder, and rename any `AGBOARD_*` variables in your shell profile to `AGPJ_*`:

```sh
agboard stop
mv ~/.agent-board ~/.agent-project
```

Agent Project does not convert stored files. Before you start it, edit the moved folder by hand:

- In `~/.agent-project/shared/workspace.json`, change `"format": "agboard-files"` to `"format": "agpj-files"`.
- In each `task.json` under `~/.agent-project/shared/projects/*/tasks/`, change `"agentStatus": "pending"` to `"agentStatus": "idle"`. Open questions still mark the task as awaiting an answer.

Then run `agpj setup` to install the new plugin for Codex and Claude Code and to trust its Codex hooks. `agpj update` does not do this, because the plugin is new. Afterwards remove the old plugin from each agent (for example `claude plugin uninstall agent-board@agent-board`, and disable `agent-board@agent-board` in Codex), delete `~/.codex/rules/agboard.rules`, and start a new agent session.

Start the board with `agpj serve`. If you use phone access, save the ngrok token again with `agpj setup remote`, or choose Tailscale, and sign in on each phone with the passcode.
